GPU inference

Same GPU, same model, same budget. Then measure.

Open source · llm-serving-bench · Tesla T4

609 vs 384

output tokens per second at 64 users, vLLM vs SGLang, on the same GPU, model and memory budget.

Across 2,048 requests, vLLM's median user waited 1.8 seconds for the first token at 64 users, against 7.4 seconds on SGLang. AWQ 4-bit made single-user decode 2.3x faster but added only 5% throughput at 64 users, because decode is memory-bandwidth bound.

Quinnipiac · SPARK · IEEE UEMCON 2025

30s → 10s

average latency for one RAG workload: on-prem GPUs, then GCP L4, then AWS Bedrock.

30 seconds on our own GPUs, 15 on GCP L4, 10 on Bedrock. The lab moved its inference to Bedrock, even though running those GPUs was my job. The right answer is the one the numbers give, not the one that keeps your cluster busy.
