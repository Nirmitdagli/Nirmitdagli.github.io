          GPU performance · open source
          
LLM Serving Bench and Fused GPU Kernels

          

            
The hardware context
NVIDIA Tesla T4 (16 GB, 320 GB/s). Qwen2.5-1.5B in fp16 and AWQ int4, 512 input and 128 output tokens, identical memory budget per engine.

            
The memory constraint
Decode is memory-bandwidth bound: every step reads all weights and the KV cache. Softmax, RMSNorm and SwiGLU move far more bytes than they compute.

            
My core contribution
An async load generator that times every streamed token and sweeps 1 to 64 concurrent users across vLLM and SGLang, plus fused Triton kernels (forward and backward) and a tiled GEMM checked against cuBLAS.

          

          
AWQ int4 cut decode 2.3x (20.0 → 8.5 ms/token) · fused kernels reach 78% of T4 peak bandwidth

          AI in production · Sidecoach Sports
          
AI Gateway and Agent Platform

          

            
The agentic context
A youth sports platform adding LLM features and AI operations, under COPPA and FERPA, with no platform team before me.

            
The security constraint
Every team needs its own access and spend limits, no student PII may reach a model, and every agent action has to be traceable and reversible.

            
My core contribution
An AI gateway in front of LLM APIs (Entra ID OIDC, per-team API keys, PII redaction, OpenTelemetry tracing), an MCP agent service with RAG, and an SRE agent suite on Azure AI Foundry that triages alerts, summarizes incidents and runs runbooks behind approval gates.

          

          
3 AI services in production within 3 months · human approval on every runbook action

        


        
        

          Distributed platform · Zycus
          
Multi-Cloud Kubernetes Platform for Enterprise SaaS

          

            
The context
Enterprise procurement SaaS for global customers, across 7 environments (4 production) on AWS, Azure, GCP, Rancher and VMware.

            
The scale constraint
2,000+ servers to move onto Kubernetes without downtime, then a ransomware attack that took 1,500+ servers and 80 to 90 services per environment offline.

            
My core contribution
Led the migration into 50+ clusters (EKS, AKS, GKE, Rancher, OpenShift) with ArgoCD GitOps, Kyverno policies and Velero backups. Led a team of 5 standardizing Terraform, Ansible and Jenkins provisioning. First responder in the recovery: restored the fleet, re-architected the network (Transit Gateway, segmented VPCs, 20 Palo Alto firewalls) and ran 4 months of hardening with Zscaler, CrowdStrike and CyberArk.

          

          
Restored 1,500+ servers across 7 environments in 7 days · provisioning time cut about 40%
